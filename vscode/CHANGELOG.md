# Changelog

## 0.3.0 — 2026-10-25
- Menus and messages in English, Spanish and French (VS Code display language).
- New setting `asterView.language` for the viewer page.
- `aster-view` is found automatically in `PATH`, `~/.local/bin` and conda environments.
  When it is missing, the error offers the settings or the installation guide.
- `asterView.openIn`: `browser` (the old value `navegador` still works).
- If the viewer process stops, the tab shows a message and a button to open it again.

## 0.2.0 — 2026-10-24
- "Open With… → Aster View" custom editor, status-bar button, editor-tab context menu.

## 0.1.0 — 2026-10-24
- First version: command to open a `.med` file in Aster View.
